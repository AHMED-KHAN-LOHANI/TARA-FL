How It Works

  1. Clients receive the global model and train locally on their private data for a few epochs.
  2. Client Updates (parameter differences) are sent to the server; malicious clients may poison theirs.
  3. Trust Engine runs the five-stage pipeline: robust update geometry (median centroid + MAD z-scores) → Tcurr = 1/(1+a²) → EMA memory (0.6/0.4) → persistence penalty (γ = 0.8) → composite T = 0.6·Thist + 0.4·Tcurr − 0.2·P.
  4. Trust Zones: High ≥ 0.75 (full weight), Medium 0.40–0.75 (reduced), Low 0.20–0.40 (heavy down-weight), Quarantine < 0.20 (weight 0, recoverable after 2 clean rounds).
  5. Risk Assessor: R = 0.30·(1−min T) + 0.25·distance anomaly + 0.25·(1−mean T) + 0.20·suspicious share.
  6. Adaptive Aggregation: Low R < 0.30 → FedAvg; Medium → trust-weighted trimming; High R ≥ 0.60 → coordinate-wise median. Weights follow W(t+1) = Σ(nk·T̃k / Σ nj·T̃j)·ΔWk with T̃k = max(Tk, 0.05).
  7. Global Model updates and the cycle repeats. If every client is quarantined, the current model is kept.

Key Novelty

Unlike fixed aggregation or one-shot filtering, TARA-FL re-selects the defense every round from live risk signals. In the demo the four aggregation rules run on the same client updates, so any gap you see between the curves is purely the aggregation rule.

About TARA-FL

TARA-FL (Trust-Aware Robust Adaptive Federated Learning) is our capstone project. The server dynamically evaluates client trustworthiness, classifies clients into trust zones, assesses round-level risk, and picks the aggregation strategy accordingly.

This demo shows the core loop — dynamic trust scoring, quarantine & recovery, adaptive routing — under IID and non-IID data with four attack types.

Research Question

Can a federated learning server dynamically adjust its aggregation defense based on the trustworthiness of participating clients, while preserving useful updates from honest clients in highly non-IID environments?

Aggregation Strategies

LowFedAvg

Selected when risk is LOW (R < 0.30) — simple and efficient, no defense overhead on a calm day.

MediumTrust-Weighted Trimming

Weights each client's update by its trust score and trims the anomalous outliers — suspicious clients lose influence.

HighCoordinate-wise Median

Strong Byzantine-resistant aggregation for R ≥ 0.60 — removes the influence of extreme updates entirely.

Technology

This demo is a single plain HTML file with hand-drawn SVG charts — no framework, no build step, no network requests — so it runs by just double-clicking demo/index.html. The five-stage trust engine, zone routing and adaptive aggregation follow the report exactly; client updates are synthetic 8-D vectors and the accuracy/loss trajectories come from a response model calibrated to the reported results, not the original MNIST training loop. The full implementation (in this repo) trains the small MNIST CNN with real client partitions.
